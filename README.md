An offline guide and progress tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: a checklist that saves what you have earned, a six-stage roadmap to the platinum, and the ten missable trophies in the order they lock. Every trophy carries a written route in its own words and the guide sites that route draws on. No build step, no network, no dependencies — plain HTML, CSS and ES modules that open in a browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
